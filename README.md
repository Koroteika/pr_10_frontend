# 🐦 Классификация птиц — Streamlit Frontend

## 📋 Описание

Данный репозиторий содержит пользовательский интерфейс для классификации изображений птиц. В качестве веб-фреймворка используется **Streamlit**. Приложение отправляет изображение на FastAPI-бэкенд и отображает результат классификации с визуализацией вероятностей.

**Пользователи могут:**

- ✏️ Нарисовать птицу прямо в браузере на интерактивном холсте
- 📁 Загрузить изображение со своего устройства
- 📊 Увидеть предсказанный класс, уверенность модели и распределение вероятностей по классам

| Класс | Описание |
|---|---|
| Asian Green Bee-Eater | Зелёная щурка |
| Brown-Headed Barbet | Бурохохлый бородастик |
| Common Kingfisher | Обыкновенный зимородок |

## 🛠 Используемые технологии

- **Python** 🐍: основной язык программирования
- **Streamlit** 🎈: фреймворк для создания веб-интерфейса
- **streamlit-drawable-canvas** ✏️: интерактивный холст для рисования
- **Pillow** 🖼️: предобработка изображений перед отправкой на API
- **Matplotlib** 📊: визуализация распределения вероятностей
- **Requests** 🌐: HTTP-запросы к FastAPI-бэкенду

---

## 📁 Структура проекта

- **`app.py`**
  Приложение на Streamlit, позволяющее:
  - 🤖 Загрузить изображение или ✏️ нарисовать его в интерактивном холсте
  - 📤 Отправить изображение на сервер с помощью HTTP-запроса
  - 📊 Визуализировать результат классификации в виде графика

- **`requirements.txt`**
  📦 Список зависимостей, необходимых для работы проекта.

- **`.python-version`**
  🐍 Фиксирует версию Python (3.12) для корректного деплоя на Streamlit Cloud.

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/Koroteika/pr_10_frontend.git
   cd pr_10_frontend
   ```

2. **Создайте и активируйте виртуальное окружение:**

   **На Windows:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **На macOS/Linux:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Установите зависимости:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Запустите приложение:**

   ```bash
   streamlit run app.py
   ```

5. **Перейдите по адресу** [http://localhost:8501](http://localhost:8501) и протестируйте работу приложения:

   - Выберите режим **«Загрузить изображение»** и укажите файл, либо
   - Выберите режим **«Нарисовать на холсте»** и создайте свой рисунок для классификации.

---

## ⚙️ Как это работает

1. 🖼️ Пользователь загружает или рисует изображение птицы
2. 🔄 Приложение конвертирует изображение в RGB и сохраняет в JPEG-байты
3. 📤 Изображение отправляется POST-запросом на FastAPI-бэкенд (`/predict`)
4. 📊 Результат отображается в виде метрик и горизонтальной диаграммы вероятностей
